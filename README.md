# PHOR COFFEE (แบบหลายหน้า)

เว็บตัวอย่างสำหรับร้าน PHOR COFFEE ถนนร่มเกล้า 1 ลาดกระบัง แบ่งเป็น 4 หน้า

| ไฟล์ | หน้า |
|---|---|
| `index.html` | ข้อมูลร้าน |
| `menu.html` | เมนู (แฟ้มกระจก 3 หมวด กดรูปเพื่อดูรูปใหญ่) |
| `location.html` | สถานที่ร้าน |
| `contact.html` | ติดต่อ |

ไม่ต้องติดตั้งอะไร เปิด `index.html` ในเบราว์เซอร์ได้เลย

## แก้ข้อมูลร้าน

ข้อมูลทั้งหมดอยู่ใน `assets/data.js` ไฟล์เดียว (ชื่อร้าน เวลาเปิด เมนู ราคา ที่อยู่ เบอร์โทร LINE รูป) แก้แล้วทุกหน้าเปลี่ยนตาม

รูปเมนูที่เก็บในเว็บเองอยู่ใน `assets/img` (ไฟล์ขนาดเล็กชื่อเดียวกันอยู่ใน `assets/img/sm` ใช้กับรูปย่อ) ถ้าเพิ่มรูปใหม่ให้ใส่ทั้งสองที่ แล้วใส่ `img` กับ `pos` (จุดโฟกัสของรูป) ให้เมนูนั้นใน `data.js`

## 2 ภาษา (ไทย / อังกฤษ)

ปุ่มเลือกภาษาอยู่มุมขวาบน ไทยเป็นค่าเริ่มต้น เว็บจำภาษาที่เลือกไว้ทุกหน้า ลิงก์ที่ลงท้ายด้วย `?lang=en` จะเปิดเป็นภาษาอังกฤษทันที

- ข้อความของหน้าเว็บ (เมนูด้านบน ปุ่ม หัวข้อ) อยู่ใน `assets/i18n.js`
- ข้อมูลร้าน (เมนู ที่อยู่ รีวิว รูปเลื่อน) อยู่ใน `assets/data.js` ช่องที่ลงท้ายด้วย `En` คือภาษาอังกฤษ เช่น `name` กับ `nameEn` ถ้าแก้ภาษาไทยให้แก้ภาษาอังกฤษด้วย

## รูปเลื่อนในหน้าข้อมูล

รูปข้างข้อความแนะนำร้านเปลี่ยนเองทุก 5 วินาที แก้รายการรูปได้ที่ `aboutPhotos` ใน `assets/data.js`

หน้าตาอยู่ใน `assets/style.css` ส่วนการทำงานของแต่ละหน้าอยู่ใน `assets/home.js`, `menu.js`, `location.js`, `contact.js`

## ก่อนขึ้นเว็บจริง

- [ ] ใส่ชื่อเมนูและราคาจริง (ตอนนี้ราคาเป็นตัวเลขสมมติ)
- [ ] เช็กเวลาเปิดกับร้าน (Google Maps และเพจ Facebook บอก 07:30–18:00 ป้ายหน้าร้านบอก 7:00)
- [ ] ขออนุญาตใช้รูป (รูปจาก Google Maps และเพจ Facebook ของร้าน) หรือเปลี่ยนเป็นรูปที่ร้านให้มา แล้วเก็บไว้ใน `assets/img`
- [ ] ลบบรรทัด `<meta name="robots" content="noindex, nofollow">` ในทั้ง 4 หน้า
